STRINGS:
	Immutable type - cannot be changed once created; any modification creates a new string
	Encoding - UTF-8, UTF-16; how to convert between byte[] and strings
	
String Methods -
	Interning - stores one instance of each unique literal string in the intern pool, compiler usually handles for literals
	Comparison - String.Equals() is more flexible than '==', and can be overwritten
	Manipulation -
		Substring
		Replace
		Split
		Join
		Trim
		Format
		Concat
	Regular Expressions (Regex) - complex pattern matching, pasrsing, validation
	
String safety - avoid concatenation for SQL queries (look this up)

Span<T> and Memory<T> - slice and manage strings without new allocations, helping garbage collection
